# API

Ce site expose quelques API publiques, utilisées en interne mais librement
accessibles. Cette page les liste et pointe vers leur documentation
respective, disponible sur la route `docs` de chaque API.

## Liste des API

### [Logo](/api/logo)

Génère dynamiquement le logo du site au format SVG, avec la possibilité de
personnaliser ses couleurs, la présence du bouclier et de l'espacement des
bords.

→ [Documentation de l'API Logo](/api/logo/docs)
